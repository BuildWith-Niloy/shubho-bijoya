# Shubho Bijoya eye blink update

This package contains the site with a subtle, periodic blink added to both doodle characters in the existing background illustration. The background art and page layout are unchanged.

To publish on GitHub Pages, replace the matching `index.html`, `script.js`, and `style.css` in the repository with these versions and push the commit to the `main` branch. Keep `bijoya-background.webp` alongside them.
